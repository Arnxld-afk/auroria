A client that is already in the game when it opens

Every Fabric and Quilt profile gets the Auroria Client: a movable HUD, zoom, freelook and a set of performance mods, installed the first time you press Play.

Try it. Press W, A, S, D and click anywhere on this panel. The HUD on the right is live.

  • FPS, CPS, ping, coordinates, clock and memory
  • Keystrokes, armour and potion effects
  • Right Shift opens the HUD editor, C zooms
  • Sodium, Lithium, FerriteCore and more, added automatically

Mods, packs and shaders without leaving the launcher

Browse Modrinth inside Auroria, sort by downloads, and install in one click. Installed mods get on and off switches and an Update all button. Mods a server needs install themselves on first Play.

A skin you can actually look at

The skins page shows your character in 3D with idle, walk, run, wave and crouch animations. Drag to turn it. Upload a PNG, wear it on your account and switch capes. The model next to the title is the same viewer.

If Windows warns you

The exe is not code-signed yet, so Windows may show "Windows protected your PC". Choose More info, then Run anyway.

Sign-in note

By default Auroria signs in through the Minecraft Launcher's public app ID. Microsoft does not officially allow that and could block it. You can register your own app and paste its ID in Settings.

What it covers

The Auroria Client needs Fabric or Quilt, so 1.14 and newer. Vanilla, Forge and NeoForge profiles get the Auroria menu look only.
